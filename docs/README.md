# Cedros Authoring guides

Use these guides to build a customization and add it to your Cedros website. If you're new to Cedros, start with the [main README](../README.md).

## Choose what to build

| Goal | Guide |
| --- | --- |
| A landing page, comparison, interactive guide, or other distinct page | [Custom pages](pages.md) |
| Consistent colors, typography, navigation, and styling across the site | [Custom themes](themes.md) |
| A booking process, member area, integration, or reusable feature | [Custom extensions](extensions.md) |

Each guide takes you through creating a project, editing its source, checking your work, and adding it to your site. Creating local files and publishing a site change are separate steps.

## Get help along the way

- [Work with an AI assistant](ai.md): example briefs and the context your assistant needs.
- [Troubleshooting](troubleshooting.md): setup, installation, previews, and package errors.
- [Compatibility and advanced options](compatibility.md): supported tools, runtime versions, and package contracts.
- [Project tools](../tooling/README.md): how the generator, starter files, and shared kits are organized.
