# __CEDROS_THEME_DISPLAY_NAME__ Block Variant Map

| Block | Default | Visual character |
|---|---|---|
| entryHeader | `detail-header` | Clear identity and hierarchy for detail views. |
| entryActions | `actions-row` | Compact, familiar action placement. |
| hero | `feature` | Strong lead section without custom behavior. |
| contentCard | `grid` | Responsive content grouping. |
| contentMedia | `media-stack` | Media-led vertical rhythm. |
| relatedContent | `related-grid` | Scannable related resources. |
| support | `support-card` | Bounded secondary help. |
| article | `article-shell` | Comfortable long-form frame. |
| paywall | `pay-gate` | Explicit access boundary. |
| sidebar | `rail` | Stable supporting navigation. |
| toc | `outline` | Structured document navigation. |
| controls | `toolbar` | Dense but familiar controls. |
| breadcrumbs | `trail` | Quiet route context. |
| pagination | `pager` | Conventional sequence navigation. |
| prose | `docs` | Readable documentation treatment. |
| codeBlock | `terminal` | Clear technical content framing. |

Each variant uses Cedros kernel styling and inherits this theme's tokens. Do not invent values: unregistered names have no kernel CSS. Surface overrides must use the same styled catalog supported by the selected block.
